# 部品と価格の表

**計算はこの表の値段で** してください(授業用の架空の固定価格・税別)。必要なものだけ選びます。全部使う必要はありません。

> 「似ている実際のサービス」は、調べるときの手がかりです。実際の料金とは違います。
> 実際のサービスと料金まで調べた人は、この表の計算に **加えて** 書いてください(⭐ 追加点)。

## 毎月の費用

### 配る・受ける

| 部品 | 月額 | 説明 | 似ている実際のサービス |
| --- | --- | --- | --- |
| 静的ホスティング(CDN つき) | 3,000円 / サイト | HTML・画像などを配る。プログラム(PHP)は動かない。アクセスが多くても料金は同じ | Cloudflare Pages / Workers、S3 + CloudFront |
| CDN | 10,000円 / サイト | 画像などを、見る人の近くから配る。サーバーの前に置く | Cloudflare、CloudFront |
| WAF | 10,000円 / サイト | 攻撃のリクエストを止める(第6回) | Cloudflare WAF、AWS WAF |
| ロードバランサ | 5,000円 | 2台以上のサーバーに振り分ける。壊れた台には送らない | AWS ALB |
| 待合室 | 15,000円 | 混んだとき「順番にご案内します」と出して、入る人数をしぼる | Cloudflare Waiting Room |

### プログラムを動かす

PHP の版が変わっても、同じ数字で計算してかまいません。

| 部品 | 月額(1台) | 能力(PHP・毎秒) | 説明 |
| --- | --- | --- | --- |
| 仮想サーバー 小(2コア・4GB) | 8,000円 | 30 リクエスト | OS の更新は **自分たち** でする |
| 仮想サーバー 中(4コア・8GB) | 16,000円 | 60 リクエスト | 同じ |
| 仮想サーバー 大(8コア・16GB) | 32,000円 | 120 リクエスト | 同じ |
| コンテナの実行サービス | 10,000円 | 30 リクエスト | Docker のイメージを渡すと動かしてくれる。OS の更新は **任せる** |
| └ 自動で台数を増やす | 0円 + 増えた分だけ **1台1時間 20円** | — | 混むと自動で増える(増えるまで約3分)。**時刻を決めて** 増やすこともできる。コンテナだけ |
| 今のデータセンターを続ける | 120,000円 | 60 リクエスト | 今のサーバー1台・回線100Mbps。新しい機器にするなら X社の値段 |
| └ 回線を 1Gbps にする | +60,000円 | — | データセンターを続けるときだけ |

似ている実際のサービス: 仮想サーバー = AWS EC2・さくらのクラウド、コンテナ = AWS ECS(Fargate)・Google Cloud Run
