# 【見本】ヤマネコ精工 コーポレートサイトのご提案

> 授業で説明した例を、フォーマットの形にしたもの。**会社は架空**。
> 課題(ツキノワ製菓)とは条件が違うので、**そのまま写しても答えになりません**。書き方の見本です。
> 料金は 2026年11月に調べたもの(1ドル = 150円で計算)。

## 0. この提案の一言まとめ

年に1〜2回しか更新しないサイトに、WordPress と月2万円のサーバーは必要ありません。**静的なサイト** にして CDN から配り、記事は **GitHub** で管理します。攻撃される所が減り、複数人で更新でき、費用は **月2万円 → 約3,000円** になります。

## 1. 現状の問題と原因

| 問題 | 根拠 | 原因 |
| --- | --- | --- |
| セキュリティが心配 | WordPress を使っているが、CMS の機能はほとんど使っていない | 使わないのに、本体・プラグイン・PHP・データベースの更新が必要 |
| 記事のバックアップがない | 資料は担当者の PC だけ | 管理する場所と決まりがない |
| 表示が遅いことがある | 画像が重い。ニュースの更新のときに遅い | 画像の大きさ。毎回 PHP とデータベースでページを作っている |
| 料金が高い | 月2万円(ビジネスプラン) | 使っていないメールなどの機能も入っている |
| 見られないことがあった | レンタルサーバー会社の障害が数回 | 1つの会社の1か所に頼っている |

## 2. 今までの案の評価

| 案 | 良い所 | 足りない所 |
| --- | --- | --- |
| WordPress のまま、別のサーバーへ | 移すのが楽 | 困りごと(セキュリティ・更新の手間)が残る |
| クラウドの仮想サーバー(IaaS)に移す | 自由に設定できる | OS・Web サーバーの更新が **自分たちの仕事** になる。手間が増える |

## 3. ご提案する構成

```text
社員 ─ PR ─→ GitHub(非公開) ─ 自動公開 ─→ 静的ホスティング + CDN ←─ 見る人
              記事・画像・履歴              (Cloudflare Pages / Workers)
```

- **静的ホスティング**: ページは開いた人によって変わらない → ファイルを配るだけでよい。PHP もデータベースも要らないので、**攻撃される所が減る**
- **GitHub の非公開リポジトリ**: 履歴がそのままバックアップになる。PR で、別の人が確認してから公開する。社内のエンジニア・デザイナーは GitHub を使える
- **画像**: 小さくして(WebP など)、CDN から配る
- **お問い合わせフォーム**: 静的なサイトでは動かないので、フォームのサービスに変える(今あるか、お客さんに確認)

**ほかに考えた案**: AWS の S3 + CloudFront。すでに AWS を使っている会社ならこちら。今回は使っていないので、設定が少ない Cloudflare にした(公式は、新しく作るなら Workers を勧めている。静的なファイルを配るだけなら、どちらでも同じことができる)。社内に Git のシステムがあれば、GitHub の代わりに使う。

## 4. 監視と運用

| 何を見る | いくつになったら | だれに | 最初にすること |

- **更新**: ブランチ → PR → プレビューで確認 → 別の人が承認 → マージで公開

## 6. 移行の手順と、戻し方

| 順番 | すること | 失敗したら |
| --- | --- | --- |
| 1 | 今のサイトの中身を全部保存する(ページ・画像・URL の一覧・データベース) | — |
| 2 | 静的なサイトを作り、仮の URL で確認する | 今のサイトはそのまま |
| 3 | 古い URL から新しい URL への転送を用意する | — |
| 4 | DNS を切り替える(**前日までに TTL を短く** する) | DNS を元に戻す(今のサーバーはまだ動いている) |
| 5 | 1か月、両方を残して様子を見る | 同じ |
| 6 | レンタルサーバーを解約する(**ドメインの契約が一緒になっていないか** 確認してから) | — |

**リスク**: 無料プランには、止まらない保証(SLA)がない。Cloudflare も2025年11月18日に大きな障害があった。会社案内のサイトなら受け入れられるか、お客さんと決める。

**確認したいこと**: お問い合わせフォームはあるか / ドメインはどこで契約しているか / メールは本当に1通も使っていないか(自動の通知など)

## 7. 自分の判断

- 使った資料: Cloudflare Pages の上限のページ、GitHub の料金のページ(どちらも 2026年11月25日)
- AI に頼んだこと: 移行の手順のたたき台
- 直した所: AI の案には「切り替えたらすぐ解約」とあったが、**戻せなくなる** ので、1か月両方を残すことにした
