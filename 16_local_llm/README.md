# 第16回: 自分のPCでAIを動かす(ローカルLLM)

授業では、講師の PC のスクリーンショットで見ます。**授業の中で何かを入れる必要はありません。**
家の PC で試してみたい人のために、手順と注意をまとめました(**任意**。課題ではありません)。

> アプリもモデルも **無料** です。**学校の PC には入れないでください。**

## フォルダ構成

```
16_local_llm/
└── sample/
    └── body.json   ← ローカルの API に聞くときの中身(手順4)
```

## 試す前に確かめること

- **メモリ**: 8GB なら 4B ほどの小さいモデル、16GB なら 8B ほどまでが目安(授業の 🧩 の表)
- **ストレージの空き**: モデル1つで **数GB〜十数GB**。空きが少ない PC ではやめておく
- **回線**: 大きなファイルをダウンロードする。スマホのテザリングでは使わない
- **ライセンス**: モデルのページで、使ってよい範囲を読む

## 手順1 LM Studio を入れる

公式のページ https://lmstudio.ai からダウンロードして入れる。似た名前のほかのサイトから入れない。

## 手順2 モデルを探して、ダウンロードする

1. 左の **検索**(虫めがね)で、モデルを探す
2. **自分の PC で動くか** の表示を見る。動かない・ぎりぎりのものは選ばない
3. はじめは **小さいモデル**(4B〜8B、`Q4` や `4bit` の印)を選ぶ

## 手順3 話してみる

チャットの画面で、上からモデルを選んで話す。**Wi-Fi を切っても** 答えることを確かめてみる。

## 手順4(発展) ローカルの API に聞く

1. **Developer** の画面で、サーバーを起動する(`http://localhost:1234`)
2. `sample/body.json` の `model` を、画面に出ているモデルの名前に書き換える
3. `sample` フォルダでターミナルを開いて、次を動かす

```sh
# Mac
curl http://localhost:1234/v1/chat/completions -H "Content-Type: application/json" -d "@body.json"

# Windows(PowerShell)は curl.exe と書く
curl.exe http://localhost:1234/v1/chat/completions -H "Content-Type: application/json" -d "@body.json"
```

返ってきた JSON の `content` に、答えが入っています。

## 気をつけること

- **ローカルネットワークに公開** する設定は **オフのまま** にする(ほかの人があなたの PC の AI を使えてしまう)
- モデルのファイルは **`.safetensors`** などの安全な形式を選ぶ。知らないサイトのファイルは入れない
- 小さいモデルは、**それっぽいウソ**(ハルシネーション)が多め。答えは確かめる
- 画像を作るときは、**だれかの作品に似せない・実在の人を作らない**。作品に使ったら、AI で作ったと書く
- 使わないときは、アプリを閉じる(メモリをたくさん使う)

## 片付け

モデルは LM Studio の **My Models** から消せます。アプリを消しても、モデルのファイルが残ることがあるので、先にモデルを消してください。
