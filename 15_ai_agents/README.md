# 第15回: AIエージェントを使いこなす

**Claude Code** と **Codex** が `cafe-site` を直すところを、講師の画面で見ます。今日は見るのが中心で、手を動かす課題はありません。

> Claude Code と Codex は、**有料のプラン** で使うのが基本です。授業の課題には入れません。
> 使ってみたい人は、料金・上限・学習に使うかの設定(入れた文章やコードを、会社が次の AI の学習に使うか。第14回)を、**公式のページで確かめてから** 自分で決めてください。

## フォルダ構成

```
15_ai_agents/
└── sample/
    ├── AGENTS.md                     ← AI への説明書(Codex など、多くのエージェントが読む)
    ├── CLAUDE.md                     ← Claude Code 用の説明書。1行目で AGENTS.md を読み込む
    └── skills/
        └── pr-description/
            └── SKILL.md              ← スキル: PR の説明を書く手順
```

## 自分のリポジトリで使うとき(総合演習など)

`cafe-site` のいちばん上のフォルダに置きます。

| ファイル | 置く場所 |
| --- | --- |
| `AGENTS.md` | `cafe-site/AGENTS.md` |
| `CLAUDE.md` | `cafe-site/CLAUDE.md` |
| `skills/pr-description/` | Claude Code: `cafe-site/.claude/skills/pr-description/`<br>Codex: `cafe-site/.agents/skills/pr-description/` |

- 両方のツールを使う人は、スキルを両方の場所に置きます(同じファイルでよい)
- 自分の作品に使うときは、`AGENTS.md` の「構成」「コマンド」を **自分の作品に合わせて** 書き換える
- 説明書は **お願い** です。守られないこともあります。止めたいことは、ツールの **権限の設定** で止めます
- 置き場所や読み込み方は、ツールの更新で変わることがあります。公式のドキュメントで確かめてください
