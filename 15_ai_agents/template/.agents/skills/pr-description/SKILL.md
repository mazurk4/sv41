# PR の説明を書く

1. `git diff main...HEAD` で、このブランチで変えたことを読む
2. `.github/pull_request_template.md` があれば、その形で書く。なければ、次の3つを書く
   - 何を変えたか
   - なぜ変えたか
   - 確認したこと(テストの結果・ブラウザで見たこと)
3. 最後に、次の2つを足す
   - **AIに頼んだこと**: どんな頼みごとをしたか
   - **人が確かめること**: AI が自分では確かめられなかったこと(スマホでの見た目など)
4. やさしい日本語で書く。1つの文は短くする
