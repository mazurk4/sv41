# SV41 配布資料

SV41(後期)の授業で使うサンプルコードです。

## 使い方

```sh
git clone https://github.com/mazurk4/sv41.git
cd sv41
```

Git が使えない場合は、GitHub の「Code」→「Download ZIP」でダウンロードして展開してください(フォルダ名は `sv41-main` になります)。

> Windows の人は **PowerShell** で実行してください(コマンドは Mac と同じです)。
> コマンドプロンプトでは動かないコマンドがあります。
> また、OneDrive で同期しているフォルダ(デスクトップ・ドキュメントなど)は避けてください。
