# SV41 配布資料

SV41(後期)の授業で使うサンプルコードです。

## 使い方

```sh
git clone <このリポジトリのURL>
cd <このリポジトリのフォルダ>
```

Git が使えない場合は、GitHub の「Code」→「Download ZIP」でダウンロードして展開してください。

> Windows の人は **WSL 側のホームフォルダ(`~/`)** に置いてください。
> `/mnt/c/...`(Cドライブ側)に置くと、Docker の動作が遅くなったり、ファイルの変更が反映されなかったりします。
