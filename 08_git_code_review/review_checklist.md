# レビューのチェックリスト

相手の PR を、上から順に確かめましょう。**読むだけでなく、ページを開いて** 確かめます。

## 目的

- [ ] PR の説明と、変更の中身が合っているか

## 動き

- [ ] ページを開いて、表示されるか
- [ ] リンク・ボタン・フォームが、ちゃんと動きそうか

## 内容

- [ ] 誤字はないか
- [ ] 値段・日付・時間は正しいか
- [ ] **ほかのページと矛盾していないか**(メニュー・営業時間・定休日)

## 見た目

- [ ] スマホの幅でも崩れないか(Chrome の開発者ツールで試す)

## 使いやすさ

- [ ] 画像に `alt` があるか
- [ ] 入力欄に `label` があるか

## 安全

- [ ] パスワードや個人情報が入っていないか
- [ ] 外から入ってきた値を、そのまま HTML に入れていないか(第5回の XSS)

## 余計なもの

- [ ] 関係のないファイルが入っていないか
- [ ] 消し忘れはないか(メモ・古いファイル・デバッグ用のコード)

---

## コメントの書き方

- **人ではなく、コードについて** 書く
- **なぜそう思うか**、理由を添える
- **どうしたらいいか** まで書く(分からなければ質問でよい)
- 細かいことには `nit:`、分からないことには `質問:` を付ける
- 良いところも書く
